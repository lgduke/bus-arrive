CORS 우회 프록시 사용 (웹 브라우저 필수)

서울시 버스 API(ws.bus.go.kr)는 브라우저 직접 호출 시 CORS 보안 차단이 발생하므로 프록시 경유를 권장합니다.

인증키 발급 방법 (무료 / 즉시 승인)

  1. data.go.kr (공공데이터포털) 로그인
  2. '서울특별시_정류소정보조회 서비스' 검색 후 활용신청
  3. 마이페이지에서 일반 인증키(Encoding) 복사 후 위에 붙여넣기

스마트폰 앱 설치 & Git 저장 안내

1. Git 저장 및 무료 웹 호스팅 방법

보안 정책상 제가 직접 사용자의 Git 계정에 푸시할 수는 없으나, 아래 순서대로 1분 만에 올리실 수 있습니다:

  1. 우측 에디터의 코드를 복사하여 index.html 파일로 저장합니다.
  2. GitHub에서 새 저장소(Repository)를 만들고 index.html을 업로드합니다.
  3. 저장소의 Settings > Pages에서 Branch를 main으로 설정하면 전용 모바일 앱 URL이 생성됩니다.

2. 스마트폰 홈 화면에 앱처럼 추가

  • 아이폰 (Safari): 하단 중앙 공유(↑) 버튼 터치 → '홈 화면에 추가' 선택
  • 갤럭시 (Chrome/삼성인터넷): 우측 상단 메뉴(⋮) 터치 → '현재 페이지 추가 > 홈 화면' 선택
